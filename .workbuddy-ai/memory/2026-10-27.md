## 第三轮：P1-5 回放台收尾 + P1-4 结构门（同日续）

### P1-5 选路回放台（已闭环）
- `tools/routing_replay.py`：纯标准库离线策略评估。结果模型两级收缩
  `(节点,域名)→节点全局→全局`，`PRIOR_STRENGTH=5`；4 策略（轮询/加权/LinUCB 镜像/oracle）。
- 合成样本 600 条 / seed 20261027：轮询 29.7% → 加权 30.8% → **LinUCB 52.2%** → oracle 77.0%。
  LinUCB 比轮询 +22.5pp、距上界 24.8pp、可避免失败 30%、P99 与 oracle 持平（249ms）
  ⇒ 瓶颈在成功率不在时延。
- `tools/replay/sample_trace.jsonl`（600 行合成）、`tools/replay/linucb_parity.json`（Rust 生成）。
- `tools/check_replay_parity.py`：Python 镜像 vs Rust 黄金向量，容差 1e-12，实测 3.33e-16；
  变异自测扰动 alpha 1e-3 判红。
- `tools/check_routing_baseline.py`（新）：文档 §4 表格**逐格**等于回放台输出；
  实测 4 种漂移全红（改成功率/改样本数/改 seed/删 oracle 行）。
- `docs/ROUTING_BASELINE.md`（新）：方法 + 三类偏差 + 准入规则（无回放对比的选路改动不合并）。

### P1-4 模块 ↔ 文档双向结构门（已闭环）
- `tools/check_components_docs.py`（新），5 类断言：
  A 模块集合三方相等（源码↔中文表↔英文表，双向）；B 标题计数；C 每行单测数且
  **合计 == 基线通过数+忽略数 == 346**（实测与 cargo test 报数精确相等）；D 关键 API
  必须是真实标识符；E 结构文档（DATAFLOW/COMPONENTS/ARCHITECTURE）里反引号 `.rs` 必须存在。
- 落门时实测的 4 类真实失真：①「19 个」vs 实际 24 个（漏 `admin.rs` 1788 行等 5 个）；
  ② `vendor_arbitrage.rs` 中英行数 208/218 自相矛盾；③ `socks_handshake.rs` 的 API 名
