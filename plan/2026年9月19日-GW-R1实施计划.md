## 勘察结论（冻结）

1. A2 `main.rs` 必挂：`SmartProxyGateway{router,telemetry}`但A1结构体缺`telemetry`字段，GW-1必须补齐，否则编译不过。
2. A3调用`router.get_healthy_candidates()`从未定义；`ProxyContext`缺`tenant_account/transferred_bytes`（A4用），GW-1建model时一次加齐（`tenant: Option<String>`占位+`transferred_bytes: u64`），避免跨阶段大改。
3. A4 `query_provider_sla`的`?`绑定在`clickhouse 0.13`不成立，GW-4改用`format!`拼接+白名单校验provider/country。
4. 指纹首轮只做网关级基础版（Chrome头+64KB窗+TFO+Keepalive），不引入utls/boring定制ClientHello；全栈拟真延后。
5. Windows本地只能验功能，50k并发/<1ms/<50ms隔离性能数必须到Linux/Docker节点验收；eBPF/io_uring/MASQUE本轮只做spike评估不阻塞主线。
6. 依赖锁版：`pingora 0.4 / redis 0.26 / reqwest 0.12 / clickhouse 0.13 / governor 0.6 / nalgebra 0.33 / arc-swap 1.7 / dashmap 6.0`，`cargo check`先行，`parking_lot`与`tokio`混用禁跨await持锁。
7. 三家供应商（Oxylabs/BrightData/NetNut）首轮全Mock（127.0.0.1:8888/8889+10.0.0.x），真Key由用户后补走staging 1%灰度。
