# Free-path Baseline 自由链路测试基线

> 用途：后续拉齐测试基线的比对基准。一键复测：`powershell -ExecutionPolicy Bypass -File tools/ipp_free_test.ps1`。
> 判定铁律：G≠D 且 G≠V＝干净免费出口；G==V＝停手重做三路对照；G==D＝透明或直连。
> 全程 curl 加 `--noproxy '*'`（shell 代理 env 不得劫持本机检查）。

## 已知干扰与排除法

- shell 代理 env（`http_proxy`＋残缺 `no_proxy`）＋Clash 按 `Host` 头路由→请求根本不到网关。排除：`--noproxy '*'`＋`curl -v` 首行＋metrics 计数器是否涨。
- Windows 网关约 5 分钟有序退出→`000`。排除：重起＋先验 200。
- 双网关同存（Pingora 端口复用分流）→开测前 `Get-Process` 确认单实例。
- `.ps1` 中文注释＋无 BOM＝解析失败。规范：`tools/*.ps1` 一律 UTF-8＋BOM（已全量）。
- VPN 出口轮转→V 每次重测；D 长期稳定但仍每次取。
